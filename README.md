# hushyar_co

## اجرای محلی

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

برنامه در `http://127.0.0.1:8000` در دسترس است. در حالت development ورود مدیر غیرفعال است.
برای دریافت خروجی‌های Graphviz در محیط محلی، ابزار Graphviz را نیز نصب کنید (در Debian/Ubuntu: `sudo apt-get install graphviz fonts-noto-core`).

## گردش تحلیل

1. پروژه را بسازید و فایل DOCX مصاحبه را بارگذاری کنید.
2. مفاهیم و کدهای اولیه را بازبینی یا تکمیل کنید.
3. پرامپت را کپی یا دانلود کرده و در ابزار هوش مصنوعی اجرا کنید.
4. JSON برگشتی را بارگذاری کنید؛ برنامه شناسه‌ها، نقل‌قول‌ها و تفسیر شواهد، شمارنده‌ها، شش بخش مدل پارادایمی و ساختار گره‌ها و یال‌ها را اعتبارسنجی می‌کند.
5. در «تحلیل مستقل مصاحبه» مقوله‌ها، پدیده محوری و روابط را بررسی و در صورت نیاز ویرایش کنید.
6. «نمودار پارادایمی» را باز کنید. نمودار گرافیکی از تحلیل ذخیره‌شده همان پروژه ساخته می‌شود؛ شش مؤلفه و کدهای باز در گراف ساختاریافته با پیوندهای جهت‌دار نمایش داده می‌شوند. بازسازی نمودار تحلیل هوش مصنوعی را اجرا نمی‌کند. پس از ویرایش مرحلهٔ دوم، نمودار وضعیت نیازمند به‌روزرسانی می‌گیرد؛ با بازسازی، تغییرات پژوهشگر و تحلیل ذخیره‌شده هماهنگ می‌شوند.
7. نمودار را بزرگ‌نمایی کنید، جزئیات مؤلفه‌ها و شواهد را بازبینی کنید، فایل PNG یا SVG بگیرید یا با گزینهٔ چاپ مرورگر به PDF ذخیره کنید. فایل‌های Excel، JSON و Word نیز در نتایج در دسترس هستند.

فایل Word باید DOCX باشد. جدول سه‌ستونی با سرستون‌های «متن مصاحبه»، «مفاهیم معنادار» و «کد» به‌صورت خودکار پردازش می‌شود؛ ردیف‌هایی که متن مصاحبه‌شان خالی است به شاهد قبلی تعلق می‌گیرند. شناسه‌های پاراگراف و مفهوم به‌طور خودکار ساخته می‌شوند. پس از پردازش، متن شاهدها، مفاهیم و کدها را در صفحه پروژه بازبینی و در صورت نیاز اصلاح کنید.

عنوان و موضوع پژوهش را در مشخصات پروژه ثبت کنید تا در پرامپت تحلیل استفاده شوند. خروجی‌ای که وضعیت `incomplete` دارد با همین هشدار در نتایج نمایش داده می‌شود. فونت وزیرمتن به‌صورت محلی برای رابط کاربری استفاده می‌شود. تولید فایل PNG/SVG از سمت سرور به ابزار اجرایی Graphviz (`dot`) نیاز دارد؛ پیکربندی Render آن را نصب می‌کند.

## آزمون‌ها

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

## استقرار

در production مقدارهای `SECRET_KEY`، `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تنظیم کنید. ورود مدیر برای دسترسی به پروژه‌ها اجباری است. پایگاه داده SQLite در `data/` ذخیره می‌شود؛ برای Render باید دیسک پایدار متصل شود تا داده‌ها پس از redeploy باقی بمانند.
